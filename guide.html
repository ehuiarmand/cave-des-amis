1. Première connexion

  1. Ouvrez l'application dans le navigateur (souvent http://127.0.0.1:8001 si le serveur tourne en local).
  2. Saisissez nom d'utilisateur et mot de passe.
  3. Si la 2FA est activée, entrez le code à 6 chiffres (Google Authenticator, Authy, etc.).
  4. Validez pour accéder au tableau de bord.

Déconnexion : barre latérale sur bureau ; navigation du bas puis Paramètres sur mobile.

2. Navigation générale

En haut à droite : sélecteur de site pour le multi-établissements. Sur téléphone, menu principal en barre du bas.

3. Tableau de bord

  • CA, charges, bénéfice indicatif, nombre de ventes ; graphiques par catégorie et par paiement.
  • Alertes stock : articles au seuil ou en dessous.
  • Proposer commande : ouvre Achats avec une ligne pré-remplie.
  • Toutes les alertes : envoie tous les articles en alerte dans le brouillon commande.
  • Cochez des lignes puis Sélection cochée pour un sous-ensemble.
  • Tout cocher / Tout décocher pour préparer la sélection.

4. Point du jour

Vue pour la clôture ou le bilan quotidien : CA encaissé, « à régler », transactions, remises, paiements et détail des boissons vendues.

5. Ventes

Commandes

Nouvelle commande ou reprise ; lignes avec article, format, quantité, lieu intérieur/extérieur selon configuration. Stock frigo/réserve pris en compte. Validation, ticket, facture, annulations selon les droits.

Caisse et crédit client

Encaissements, soldes clients, versements sur crédit.

QR codes

Génération / impression pour tables ou espaces.

Le bouton flottant + sur Ventes ouvre l'éditeur de commande.

6. Stock

Catalogue

Articles, frigo, réserve, seuils, prix d'achat, formats de vente. Recherche, tableau compact/détaillé. Nouvel article ou modification via + ou actions ligne.

Mouvements

Historique des entrées et mouvements.

Achats fournisseurs

Commande (fournisseur, date, paiement dont crédit fournisseur). Lignes : article présent au stock ; prix et btl/casier depuis le catalogue ; casiers suggérés selon stock et seuil. Réceptionner : saisir les casiers livrés réels par ligne ; mise à jour stock et charge « Approvisionnement ». Sur téléphone, le + sur l'onglet Achats ouvre ce formulaire.

Créanciers

Dettes fournisseurs ; dépense en crédit fournisseur selon configuration.

Pertes

Sorties hors vente (casse, etc.).

Excel

Exporter le stock du site. Importer : création/mise à jour ; colonnes Frigo, Réserve, Entrées, Sorties, Stock actuel prises en compte si présentes.

7. Charges

Dépenses : date, libellé, catégorie, montant, paiement (dont crédit fournisseur). Le + sur la page Charges ouvre une nouvelle dépense.

8. Paramètres

  • Profil : nom du bar, objectif CA, seuil, préfixe factures.
  • Catégories : liste des catégories boissons.
  • Accès : utilisateurs, rôles, sites, 2FA.
  • Administration : options réservées admin (audit, données, etc.).

Les menus masqués selon le rôle ne sont pas accessibles.

9. Utilisation sur téléphone

  • Navigation basse, boutons plus grands, listes empilées, modales défilables.
  • Tableaux larges : défiler horizontalement.
  • Champs dimensionnés pour limiter le zoom intempestif.

10. Bonnes pratiques

  1. Tenir le stock à jour avant ventes et commandes.
  2. Réceptionner avec les quantités livrées réelles.
  3. Vérifier le site actif en multi-maquis.
  4. Exporter régulièrement (Excel ou JSON).
  5. Garder le serveur actif ; données en JSON et/ou SQLite selon installation.

11. En cas de problème

  • Session expirée : reconnectez-vous.
  • Action refusée : rôle ou site.
  • Import Excel : en-têtes alignés sur l'export ; article obligatoire ; prix achat requis pour les propositions commande.
  • Après mise à jour des fichiers : Ctrl+F5 pour recharger les scripts.
