1. Première connexion

  1. Ouvrez l'application dans le navigateur (souvent http://127.0.0.1:8001 si le serveur tourne en local).
  2. Saisissez nom d'utilisateur et mot de passe.
  3. Si la 2FA est activée, entrez le code à 6 chiffres (Google Authenticator, Authy, etc.).
  4. Validez pour accéder au tableau de bord.

Déconnexion : bouton Déconnexion dans la barre latérale sur bureau ; sur mobile, selon l'écran, la zone session ou les Paramètres.

2. Navigation générale

Le menu Guide dans la barre latérale (ou le menu du bas sur mobile) ouvre une page sommaire dans l'application avec des liens vers ce document pour lecture ou impression PDF.

En haut à droite : sélecteur de site pour le multi-établissements. Sur téléphone, menu principal en barre du bas.

Rôles (aperçu) : serveuse, gérant, manager, administrateur, super administrateur. Réouverture d'une journée clôturée, choix de la date de journée à traiter et certaines options d'administration sont réservés aux profils autorisés.

3. Tableau de bord

  • CA, charges, bénéfice indicatif, nombre de ventes ; graphiques par catégorie et par paiement.
  • Casiers physiques : carte récapitulative du parc (total, pleins, partiels, vides) et suggestions pour le réapprovisionnement (aligné avec Stock > Gestion casiers).
  • Plus / moins vendues : classement par quantité (bouteilles) sur l'historique du site ; le bloc « moins vendues » apparaît surtout lorsque plusieurs références différentes ont été vendues au cumul.
  • Alertes stock : articles au seuil ou en dessous.
  • Proposer commande : ouvre Achats avec une ligne pré-remplie.
  • Toutes les alertes : envoie tous les articles en alerte dans le brouillon commande.
  • Cochez des lignes puis Sélection cochée pour un sous-ensemble.
  • Tout cocher / Tout décocher pour préparer la sélection.

4. Point du jour

Vue pour la clôture ou le bilan quotidien : CA encaissé, « à régler », transactions, remises, paiements, détail des boissons vendues et détail des ventes sur la période affichée.

Sous Boissons vendues (par jour) : résumé plus / moins vendues ce jour (quantité en bouteilles), puis tableau détaillé trié par CA net. Si peu de références différentes dans la journée, le bloc « moins vendues » peut être masqué.

Clôture, vérification stock et administrateurs

  • Ouverture de caisse : si votre installation l'utilise, enregistrez l'ouverture du jour dans la zone prévue en haut de page.
  • Vérifier avant clôture : lance la vérification de stock de fermeture ; Imprimer le rapport de clôture peut être proposé ensuite.
  • Journées clôturées (réouverture) : réservé aux administrateurs — supprime la fiche de clôture et annule les écritures de stock associées. Les quantités frigo / réserve actuelles ne sont pas recalculées automatiquement : vérifiez le stock physique si besoin.
  • Super administrateur : si un bloc « journée à traiter » avec une date apparaît, appliquez cette date pour corriger ou contrôler une journée précise, puis reclôturez selon votre procédure.

5. Ventes

Quatre sous-onglets : Commandes, Caisse & Paiement, Consignes, QR Codes.

Commandes

Nouvelle commande ou reprise ; lignes avec article, format (bouteille, pack, casier, etc.), quantité, lieu Intérieur / Extérieur si les tarifs diffèrent. Stock frigo/réserve pris en compte. Validation, ticket, facture, annulations selon les droits.

Caisse & Paiement

Historique ventes : ventes finalisées sur une période (Du / Au), impression possible. Recouvrement crédits : tableau « Crédits en cours (reste à payer) », bouton Encaisser, enregistrement des versements. La section Historique des paiements liste tous les versements (y compris lorsqu'il n'y a plus de solde actif).

Consignes

Deux cas fréquents : Reliquat payé (facture payée, client n'a pas tout bu — quantité à honorer à une prochaine visite) et consigne bouteille (dépôt avec retour physique — décochez « Reliquat payé : le client reviendra boire… »).

Indicateurs : Bouteilles — retour, Reliquats à servir, Clôturées, Dépôt bouteille dû. + Nouvelle consigne : client, date, facture concernée ; pour un mélange sur une facture, colonne Reliquat (btl) par ligne puis Enregistrer. Actions possibles : Bouteille rendue, Reliquat payé (prochaine visite), Reliquat servi, Remboursé / annulé, Suppr.

QR codes

Génération / impression pour tables ou espaces.

Le bouton flottant + sur Ventes ouvre l'éditeur de commande lorsque l'onglet Commandes est pertinent.

6. Stock

Catalogue

Articles, frigo, réserve, seuils, prix d'achat, formats de vente. Recherche, tableau compact/détaillé. Nouvel article ou modification via + (catalogue actif) ou actions ligne. Bouton Perte : sortie hors vente (casse, etc.) — ce n'est pas un onglet séparé.

Mouvements

Historique des entrées et mouvements.

Achats fournisseurs

Commande (fournisseur, date, paiement dont crédit fournisseur). Lignes : article au stock ; prix et btl/casier depuis le catalogue ; quantités en casiers suggérées. Si le parc l'exige : bouton Créer des casiers vides… pour créer rapidement un casier puis reprendre la commande. Réceptionner : fenêtre avec casiers livrés par ligne ; case Ranger dans des casiers physiques (cochée par défaut) — répartition sur casiers partiels ou nouveaux casiers ; stock catalogue et onglet Gestion casiers mis à jour ; charge « Approvisionnement ». Sur téléphone, le + sur Achats ouvre ce formulaire.

Créanciers

Dettes fournisseurs ; dépense en crédit fournisseur selon configuration.

Gestion casiers

Parc de casiers physiques : codes, articles, capacités, statuts (vide, partiel, plein), mouvements. Cohérent avec le tableau de bord. Les casiers vides disponibles peuvent limiter certaines commandes fournisseur : utilisez la création rapide proposée si besoin.

Excel

Exporter le stock du site. Importer : création/mise à jour ; colonnes Frigo, Réserve, Entrées, Sorties, Stock actuel si présentes.

7. Charges

Dépenses : date, libellé, catégorie, montant, paiement (dont crédit fournisseur). Le + sur la page Charges ouvre une nouvelle dépense.

8. Paramètres

  • Profil : nom du bar, objectif CA, seuil, préfixe factures, options (brasserie unique, tarifs zone, etc.).
  • Catégories : catégories boissons (selon droits).
  • Accès : utilisateurs, rôles, sites, 2FA.
  • Administration : export JSON, sauvegardes, options avancées.

Les menus masqués selon le rôle ne sont pas accessibles.

9. Utilisation sur téléphone

  • Navigation basse, boutons plus grands, listes empilées, modales défilables.
  • Tableaux larges : défiler horizontalement (stock, recouvrement).
  • Champs dimensionnés pour limiter le zoom intempestif.

10. Bonnes pratiques

  1. Tenir le stock à jour avant ventes et commandes.
  2. Réceptionner avec les quantités livrées réelles et adapter Ranger dans des casiers physiques à votre processus cave.
  3. Vérifier le site actif en multi-maquis.
  4. Exporter régulièrement (Excel ou JSON).
  5. Garder le serveur actif ; données en JSON et/ou SQLite selon installation.

11. En cas de problème

  • Session expirée : reconnectez-vous.
  • Action refusée : rôle ou site.
  • Import Excel : en-têtes alignés sur l'export ; article obligatoire ; prix achat requis pour les propositions commande.
  • Casiers vides insuffisants : créez des casiers vides via le bouton proposé ou ajustez le brouillon de commande.
  • Après mise à jour des fichiers : Ctrl+F5 pour recharger les scripts.
